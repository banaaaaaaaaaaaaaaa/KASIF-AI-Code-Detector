What is SHAP?

SHAP is an explainability method that shows how much each feature influenced the model prediction. In this project, SHAP helps explain why the model predicted code as AI-generated, Human-written, or Mixed.

How to read the colors?

Red bar

If the bar is red, this feature pushed the prediction toward AI-generated code.

Green bar

If the bar is green, this feature pushed the prediction toward Human-written code.

Longer bar

A longer bar means the feature had a stronger effect on the prediction.

Shorter bar

A shorter bar means the feature had a smaller effect compared with the others.
